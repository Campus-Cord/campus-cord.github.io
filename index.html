Connect CampusCord to Firebase

One-time setup, about 5 minutes, free. You only do this once, and your friends never see this screen.

  1. Go to console.firebase.google.com and click Create a project. Any name works, and you can turn Google Analytics off.
  2. In the left menu, open Build → Authentication and click Get started. Under Sign-in method, turn on Anonymous.
  3. Open Build → Firestore Database, click Create database, pick a location near you and choose production mode.
  4. In Firestore, open the Rules tab, delete what's there, paste the rules below and click Publish.
  5. Go to Project settings (the gear icon) → Your apps → the </> web icon. Register an app, copy the firebaseConfig values and paste them at the top of the script in this file, where it says PASTE_HERE.
  6. Upload this file anywhere, such as Netlify Drop, GitHub Pages or Firebase Hosting, and open it. The first person to open it becomes the admin, so make sure that's you!
