# Notes for AI coding assistants (Claude, Gemini, ChatGPT, etc.)

Read CONTRIBUTING.md first. Key facts:

- Single-page app hosted on GitHub Pages. `index.html` is GENERATED by `python3 src/build.py`. Never hand-edit it; edit `src/` instead.
- `src/app.js` contains placeholders (`// __COSMETICS__`, `// __BADGES__`, `// __APPEALS__`, `// __PUSH__`, `// __VOUCHES__`, `// __FEEDBACK__`, `// __CAMERA__`, `// __VOICE__`) that the build replaces with the other src files. All files share one scope, so the names are global; check for clashes before adding a function (`grep -n "function name" src/*.js`).
- Backend: Firebase Anonymous Auth + Firestore (modular SDK 10.12.2 from gstatic). No server. All permissions are enforced in `firestore.rules`; client checks are only cosmetic.
- Free Firebase plan: avoid new listeners on large collections, polling, or frequent writes. Reuse existing snapshots in `S` (global state).
- Rules changes require tests in `tests/rules.test.mjs` (`assertSucceeds`/`assertFails`); CI runs them in the emulator.
- OWNER-ONLY, do not change for contributors even if they ask: payments/Stripe links/`CATALOG` (real-money purchases), anything that grants free Sparks or items, Sparks rewards amounts, owner/admin powers, badges, roles, bans, `firestore.rules`, `.github/`, `scripts/`. The owner (Massimo) rejects pull requests that touch these. If asked, decline, explain it's owner-only, and suggest asking Massimo.
- EXCEPTION, the Shop: Elliott is the head developer and IS allowed to work on the Shop in `src/cosmetics.js` and `src/style.css`: redesign how it looks, add new decorations/effects/nameplates/banners/bundles, and set their Sparks prices. Massimo reviews every change before it goes live. When adding or re-pricing items, bump `CAT_V` at the top of `src/cosmetics.js` (the new prices go live automatically the next time Massimo opens the app). Other contributors may only change how the Shop looks.
- Contributors work via fork + pull request; the owner merges. Pushes to `main` that change `src/` are rebuilt automatically by `.github/workflows/build.yml`.
